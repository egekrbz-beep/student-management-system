# Relational Student Management & Analytics System

A Python and SQLite application designed to manage student records, course grades, and multi-table academic reporting using relational database principles.

## Key Features
- **CSV Data Ingestion:** Automated parsing and loading of student records (`ogrenciler.csv`).
- **Relational Schema Design:** Normalized table structures linking student profiles with course grade records.
- **SQL Analytics & Reporting:** Multi-table `JOIN` queries to aggregate and display academic performance metrics.
- **Modular Scripts:** Dedicated scripts for database initialization, grade entry, querying, and pipeline execution.

## Tech Stack
- **Language:** Python 3
- **Database:** SQLite (`sqlite3`)
- **Data Format:** CSV
